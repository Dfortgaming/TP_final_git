# Dragon forge

>Site de vente de figurines pour jeux de rôles

---

## Aperçu

- **Responsive Design :** Adapté aux écrans mobiles, tablettes et ordinateurs de bureau.
- **Performance :** Code HTML5 sémantique et CSS3 pur, sans dépendances lourdes.
- **Accessibilité :** Balisage conforme aux bonnes pratiques web.

---

## Comment l'utiliser en local

Il n'y a **aucune installation ou compilation requise**. Vous pouvez consulter le site directement :

### Ouvrir directement dans le navigateur
Double-cliquez simplement sur le fichier `index.html` ou ouvrez-le avec votre navigateur préféré (Chrome, Firefox, Safari, Edge).
